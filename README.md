# El Códice de Tyria

Sitio web de fans dedicado a **Guild Wars 1**: guías, builds, profesiones,
campañas y títulos, en español.

🔗 Publicado con GitHub Pages.

## Estructura del proyecto

```
gw1-es/
├── index.html              # Página principal
├── guias/
│   └── index.html          # Página de guías
├── css/
│   └── style.css           # Estilos del sitio
├── images/
│   ├── background.jpg      # Fondo general
│   └── campaigns/          # Imágenes de las 4 campañas
│       ├── prophecies.jpg
│       ├── factions.jpg
│       ├── nightfall.jpg
│       └── eotn.jpg
└── README.md
```

> Las imágenes de `images/campaigns/` son marcadores de posición
> generados automáticamente. Sustitúyelas por capturas o artes reales
> del juego manteniendo el mismo nombre de archivo.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de tu repositorio
   (rama `main`).
2. En GitHub, ve a **Settings → Pages**.
3. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. La página quedará publicada en
   `https://<tu-usuario>.github.io/gw1-es/`.
